Пользовательский скрипт для магазина Steam и Steam Community, который добавляет дополнительную информацию об играх с [GameStatus.info](https://gamestatus.info): защиту, даты выхода, оценки, характеристики ПК и многое другое.

Во время просмотра Steam вы видите компактные бейджи с информацией на карточках игр и в шапке страницы игры — не покидая магазин.

Совместим с [Tampermonkey](https://www.tampermonkey.net/), [Violentmonkey](https://violentmonkey.github.io/), [Greasemonkey](https://www.greasespot.net/), ScriptCat и другими менеджерами, поддерживающими блок метаданных `// ==UserScript==`.

## Быстрая установка

1. Установите менеджер пользовательских скриптов (рекомендуются Tampermonkey или Violentmonkey).
2. Нажмите ссылку для установки ниже — менеджер должен открыть окно подтверждения.

**Ссылка для установки:**

```
https://raw.githubusercontent.com/NemoKing1210/steam-gamestatus/main/steam-gamestatus.user.js
```

[![Установить](https://img.shields.io/badge/⬇_Install-Steam_GameStatus-1b2838?style=for-the-badge&labelColor=66c0f4)](https://raw.githubusercontent.com/NemoKing1210/steam-gamestatus/main/steam-gamestatus.user.js)

### Установка по URL (из панели управления)

| Менеджер | Путь |
|---------|------|
| Tampermonkey | Панель управления → **Utilities** → **Install from URL** |
| Violentmonkey | Панель управления → **+** → **Install from URL** |
| Greasemonkey | Меню дополнения → **New User Script** → вставьте raw URL |

Вставьте ссылку для установки, указанную выше.

### Ручная установка

1. Откройте [`steam-gamestatus.user.js`](steam-gamestatus.user.js) в этом репозитории.
2. Скопируйте всё содержимое файла.
3. В менеджере пользовательских скриптов создайте новый скрипт и вставьте код.
4. Сохраните и включите скрипт.

## Обновления

Скрипт содержит метаданные `@updateURL` и `@downloadURL`, указывающие на raw-файл GitHub. Поддерживаемые менеджеры проверяют обновления автоматически (Tampermonkey: панель управления → интервал проверки; Violentmonkey: аналогично).

Менеджеры сравнивают установленную `@version` с удалёнными метаданными и решают, предлагать ли обновление.

## Возможности

- **Панель настроек** — кнопка в шапке для настройки положения и размера бейджа, позиции карточки, срока кеширования, очистки кеша и показа бейджей «Нет в базе»
- **Бейджи статуса на карточках игр** — главная страница магазина, результаты поиска, списки желаемого, страницы распродаж и другие списки со ссылками `/app/{id}`
- **Бейдж статуса на страницах игр** — компактный чип в `.apphub_OtherSiteInfo` рядом со ссылками Community Hub / Store Page
- **Подробные подсказки** — всплывающие окна в стиле Steam с обложкой, чипами статуса, цветными оценками и характеристиками
- **Цветовая кодировка статусов** — быстрый визуальный обзор длинного списка игр
- **Ленивая загрузка** — бейджи загружаются только когда карточки попадают в область просмотра
- **Умное кеширование** — ответы кешируются локально, чтобы снизить нагрузку на API и ускорить повторные посещения
- **Интерфейс в стиле Steam** — бейджи оформлены как `.app_tag` Steam, подсказки — как всплывающие окна магазина
- **10 языков интерфейса** — английский, русский, китайский, испанский, португальский, немецкий, французский, японский, корейский, польский (определяется по языку браузера)

## Поддерживаемые страницы

| Сайт | Шаблон URL |
|------|-------------|
| Магазин Steam | `https://store.steampowered.com/*` |
| Steam Community (хаб игры) | `https://steamcommunity.com/app/*` |

## Цвета статусов

Каждый бейдж имеет цветную точку, отражающую статус игры на GameStatus.info:

| Цвет | Статус | Значение |
|-------|--------|---------|
| Зелёный | Готово | Статус указывает, что игра готова / доступна |
| Оранжевый | Ожидание (недавно) | Статус «ожидание»; игра вышла менее месяца назад |
| Красный | Ожидание (долго) | Статус «ожидание»; игра вышла более месяца назад |
| Оранжевый | Обход защиты | Статус указывает на метод обхода защиты |
| Синий | Релиз сегодня | Игра выходит сегодня; статус может оставаться «в ожидании» |
| Серый | Статус неизвестен / нет в базе | Статус неясен или игра не найдена на GameStatus.info |
| Синий (спиннер) | Загрузка | Данные загружаются из API |

Нажатие на бейдж открывает страницу игры на GameStatus.info (или главную страницу сайта, если игра не найдена).

## Содержимое подсказки

При наведении на бейдж открывается всплывающее окно в стиле Steam, которое может показывать:

- **Шапка** — обложка, название, чип статуса, чипы AAA / защиты / группы
- **Даты** — дата выхода и дата обновления статуса, Steam ID, подписки
- **Оценки** — значения GameStatus и Metacritic с цветами в стиле Metacritic (зелёный ≥75, жёлтый ≥50, красный ниже)
- **Характеристики** — CPU, RAM, GPU, ОС, если доступны
- **Описание** — краткое описание игры
- **Подвал** — кнопка поддержки и ссылки API / GameStatus

Если игры нет в базе, окно показывает чип «Нет в базе» и список URL API, испробованных при поиске.

## Настройки

Откройте **GameStatus** в шапке Steam (или в меню менеджера скриптов), чтобы настроить:

| Настройка | По умолчанию | Примечания |
|---------|---------|-------|
| Положение бейджа (вертикальное / горизонтальное) | Сверху / Слева | Только для бейджей на карточках; чипы на странице игры остаются в шапке |
| Позиция карточки | Слева | Где открывается карточка GameStatus рядом с игрой; переключается на другую сторону, если не хватает места |
| Размер бейджа | Средний | Маленький / Средний / Большой / Очень большой; только для бейджей на карточках |
| Показывать бейджи «Нет в базе» | Вкл. | Если выключено, карточки без совпадений остаются без пометок |
| Срок кеширования (часы) | 6 | Применяется ко всем кешированным запросам; максимум 168 (7 дней) |
| Очистить кеш | — | Сразу; сохранение не требуется |

## Источник данных

Все данные об играх берутся из публичного API GameStatus.info:

```
GET https://gamestatus.info/back/api/gameinfo/game/{slug}/
```

Проект **не связан** с Valve, Steam или GameStatus.info. Информация о статусах поддерживается сообществом и может быть неполной или устаревшей. Используйте её как справочную, а не как гарантию.
